# Секретный рецепт праздничного торта для мамы

Статический интерактивный квест. Откройте `index.html` в современном браузере; сборка и установка зависимостей не нужны. Аудиофайлы хранятся в `assets/`, поэтому звук не зависит от доступности сторонних хостингов.

## Звук

- Голос куриц — [Alys, Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Chickens_demanding_food.ogg), общественное достояние.
- Музыка танца — [Happy Beat, burabotti](https://opengameart.org/content/happy-beat), CC0.
- Аплодисменты — [Applause i, Thore, Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Applause_i.ogg), общественное достояние.

## Публикация

GitHub Actions публикует содержимое репозитория в GitHub Pages при каждом push в `main`.
