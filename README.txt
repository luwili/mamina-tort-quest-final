Квест «Секретный рецепт праздничного торта для мамы»

1. Откройте index.html в браузере для просмотра.
2. Чтобы показать родителям фотографию места, где спрятаны открытки/поделки, положите фотографию рядом с index.html и назовите её surprise-place.jpg.
3. Для публикации загрузите папку целиком (index.html и surprise-place.jpg, если он добавлен) на статический хостинг, например Netlify Drop.
Если фотографии нет, на финальном экране будет показана аккуратная иллюстрация-подсказка.
